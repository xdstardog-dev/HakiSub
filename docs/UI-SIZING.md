# UI 尺寸规范

适用于首页和房间界面的新增及调整。基础变量定义在 `src/style.css` 的 `:root`；现有界面逐步迁移，不代表旧值已全部统一。

| 用途 | 尺寸 | 变量 |
| --- | --- | --- |
| 紧密间隔 | 4、8px | `--ui-space-1`、`--ui-space-2` |
| 控件内部、相关元素 | 12、16px | `--ui-space-3`、`--ui-space-4` |
| 分组和容器内边距 | 20、24px | `--ui-space-5`、`--ui-space-6` |
| 大容器内边距 | 28、32px | `--ui-space-7`、`--ui-space-8` |
| 可交互控件最小高度 | 44px | `--ui-control-min` |
| 输入框及常规主操作高度 | 至少 48px | `--ui-control` |
| 常规控件圆角 | 12px | `--ui-radius-control` |
| 桌面弹窗圆角 | 24px | `--ui-radius-dialog` |

间距优先采用 4px 倍数。边框、图标笔画和光学微调可使用其他值；不以网格为由牺牲文字可读性或点击区域。控件可随内容增高，44px 是交互区域而非图标大小。

## 对齐与响应式

- 同一容器的标题、表单、分隔线和操作区优先共用左右基线。入口弹窗桌面左右内边距为 32px，窄屏为 20px。
- 首页在 768px 切换桌面布局；弹窗在窄屏保留外边距，内容超高时滚动，并考虑安全区域。
- 房间当前最大宽度为 480px；字幕网格由成员数、可用高度及键盘状态共同决定，不强制套用固定卡片高度。
- 字号、行高和字幕动态尺寸按可读性与内容需求决定；颜色、动效和信息层级不在本尺寸规范中。

## 迁移与验收

首页入口弹窗和全局按钮、输入框最小高度已接入基础变量，其余历史样式尚未全部迁移。修改其他组件时按相邻组件成组统一，保留有意的例外；避免全局替换破坏字幕、移动键盘或弹窗滚动。验收至少覆盖桌面和窄屏、长名称、内容溢出、键盘焦点与设置弹窗。

首页创建／加入按钮采用胶囊轮廓、左侧圆形图标及粗体文字，图标和文字作为一组居中。理想字号为 20px、字距 1.5px。桌面卡片较窄，字号、图标和高度按容器宽度缩小，交互高度不小于 48px。
